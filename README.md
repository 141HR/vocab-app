# 单词卡片 (Vocab App)

基于经典 SM-2（SuperMemo 2）间隔重复记忆算法的轻量级、现代极简高颜值单词学习 Web 应用。

## 功能特色

- **内置卡组**：内置「考研英语核心词汇」精品卡组，开箱即学。
- **科学记忆**：结合 SM-2 艾宾浩斯间隔重复算法，自适应安排复习间隔。
- **真人发音**：切换至新卡片时自动播放标准英语朗读，沉浸式记忆。
- **动效体验**：3D 翻转卡片、流体进度条、完成彩花庆祝动效。
- **全天候复习**：支持「巩固复习模式」，学完当日额度后随时可继续自由温习。
- **极速键盘快捷键**：
  - `空格` / `Enter`：翻转卡片
  - `1` ~ `4`：快速评定（忘记 / 模糊 / 记得 / 简单）
  - `Esc`：退出学习
- **纯本地安全隐私**：所有卡片、学习进度与复习日志均保存在浏览器本地（LocalStorage），零服务器数据上传，100% 保护隐私。

## 本地运行

双击直接用浏览器打开 `index.html` 即可使用，或使用内置服务：

```bash
node server.js
```
访问：`http://localhost:3000`
