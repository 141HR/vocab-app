# 单词卡片 (Vocab App)

基于经典 SM-2（SuperMemo 2）间隔重复记忆算法的轻量级、现代极简高颜值单词学习 Web 应用。

## 在线体验

网站已部署上线，无需安装，点击下方网址即可在浏览器（支持电脑与手机端）直接使用：

👉 **[https://141hr.github.io/vocab-app/](https://141hr.github.io/vocab-app/)**

> **隐私安全保障**：本应用采用纯前端架构，所有卡片数据、背词记录与学习进度均保存在访问者本人的浏览器本地（LocalStorage），零服务器数据上传，100% 保护个人隐私。

## 功能特色

- **内置卡组**：内置「考研英语核心词汇」精品卡组，开箱即学。
- **科学记忆**：结合 SM-2 艾宾浩斯间隔重复算法，自适应安排复习间隔。
- **真人发音**：切换至新卡片时自动播放标准英语朗读，沉浸式记忆。
- **动效体验**：3D 翻转卡片、流体进度条、完成彩花庆祝动效。
- **全天候复习**：支持「巩固复习模式」，学完当日额度后随时可继续自由温习。
- **极速键盘快捷键**：
  - `空格` / `Enter`：翻转卡片
  - `1` ~ `4`：快速评定（忘记 / 模糊 / 记得 / 简单）
  - `Esc`：退出学习
